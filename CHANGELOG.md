# Changelog

## [1.0.0] - 2026-08-14

### Added
- Fundación full stack con Clean Architecture pragmática.
- ASP.NET Core Identity, JWT, roles, perfil y recuperación de contraseña.
- Gestión de proyectos e Ingeniería de Requisitos con MoSCoW y trazabilidad.
- Quality Center para riesgos, pruebas, defectos y métricas.
- Studio Insights, simulador, centro de aprendizaje y reportes PDF/Excel.
- Responsive design para escritorio, tableta y móvil.
- Adecuación de accesibilidad basada en NORTIC B2:2017, objetivo A/AA aplicable.
- Herramientas de tamaño de texto, alto contraste, skip link y declaración de accesibilidad.
- Rate limiting, HSTS, cabeceras de seguridad y política de seguridad.

### Quality
- GitHub Actions para backend, pruebas de dominio, integración y build de frontend.
- Documentación de accesibilidad y seguridad para mantenimiento posterior.
